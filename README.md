# make-knowledge-cards

## 项目解决什么问题

阅读长文章后，真正重要的概念、关系和限制容易被大量背景与重复表述淹没。`make-knowledge-cards` 是一个 Codex Skill，帮助用户把文章压缩成适合复习的知识卡片，同时保留原文依据，不用外部常识补全内容。

## 主要功能

- 接收用户直接粘贴的文章，或本地 `.md` / `.txt` 文件。
- 提取真正重要、彼此独立的知识点，并按重要性整理。
- 删除重复内容；每张卡片只讲一个知识点。
- 为每张卡片生成标题、核心知识、简明解释，以及原文例子或自测问题。
- 信息充分时生成 5–8 张卡片；信息不足时减少数量并说明原因，不强行凑数。
- 保留原文的条件、因果方向和不确定性，不编造原文没有的信息。

当前版本不支持网页抓取、PDF、Anki，也不提供图形界面。

## 安装方法

本项目不需要额外的 Python、Node.js 或第三方依赖。将以下目录完整复制到 Codex 的 skills 目录即可：

```text
skills/make-knowledge-cards
```

Windows 用户可以复制到个人技能目录：

```text
C:\Users\你的用户名\.codex\skills\make-knowledge-cards
```

请保留目录中的 `SKILL.md` 和 `agents/openai.yaml`。安装后重新打开或刷新 Codex，使 Skill 被发现。

## 使用方法

可以让 Skill 隐式触发，也可以显式指定 `$make-knowledge-cards`，然后：

1. 直接粘贴文章；或提供本地 `.md` / `.txt` 文件路径。
2. 说明要整理成知识卡片。
3. 检查输出的卡片数量、原文依据和自测答案。

示例：

```text
请使用 $make-knowledge-cards，把 C:\notes\学习方法.md 整理成知识卡片。
```

## 输入输出示例

输入：

```text
请把下面这段文章整理成知识卡片：

主动提取是先合上材料，尝试回忆答案，再核对材料。它不同于再次阅读，
因为回忆本身构成了练习。间隔复习是把同一内容分散到几天或几周内复习。
```

输出：

```markdown
共 2 张知识卡片

### 卡片 1｜主动提取是什么
- **核心知识：** 主动提取是在不看材料时先尝试回忆答案，再进行核对。
- **简明解释：** 回忆动作本身构成练习，因此它不同于再次阅读。
- **例子或自测问题：** 自测：主动提取与再次阅读的关键区别是什么？答案：主动提取先回忆再核对。

### 卡片 2｜间隔复习是什么
- **核心知识：** 间隔复习是把同一内容分散到几天或几周内复习。
- **简明解释：** 原文只说明了分散复习的时间安排，没有提供更多效果数据。
- **例子或自测问题：** 自测：间隔复习如何安排同一内容？答案：分散到几天或几周内复习。
```

示例只有两个可独立支持的知识点，因此输出 2 张，而不是为了达到 5 张补充或拆分原文内容。
