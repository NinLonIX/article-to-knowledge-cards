# Make Knowledge Cards

把用户提供的文章或纯文本材料压缩成可复习的知识卡片。卡片的价值来自保留原文真正重要、彼此独立的知识点，而不是把段落逐句改写或为了达到数量补充常识。

## 适用范围

- 输入可以是用户直接粘贴的文章，也可以是本地 `.md` 或 `.txt` 文件路径。
- 读取本地文件时只使用文件中的文字；Markdown 标题、列表和代码块都属于输入内容，但不要把排版本身当成知识点。
- 不抓取网页、不处理 PDF、不创建或导入 Anki、不制作图形界面。遇到这些输入时，说明限制并请用户粘贴文字或提供 Markdown/TXT 文件。

## 工作流程

1. **确定材料边界。** 先读取完整的粘贴文本或本地文件。保留原文的限定词、因果方向、条件和不确定性；不要用外部知识填空。
2. **提取候选知识点。** 找出能帮助读者理解、判断或行动的主要概念、关系、步骤、条件、证据和限制。把只提供背景、修辞或重复表达的句子降为上下文。
3. **拆成原子卡片。** 一张卡片只回答一个核心问题。若一个候选点包含两个可以分别提问的结论，就拆开；若拆开后任一部分失去原意，就保留为一张。
4. **合并重复内容。** 同义改写、同一结论的例子和前后段落的重复说明只保留一次；把补充条件合并进最相关的卡片，而不是另造重复卡片。
5. **按重要性筛选。** 优先保留文章反复强调、支撑后文、改变判断或可直接用于复习的点。不要为了凑满 5 张而把细枝末节升格为知识点。
6. **决定数量。** 信息充分时输出 5–8 张；信息不足时只输出能够由原文独立支持的卡片，并在卡片前用一句话说明“原文信息有限，因此共 N 张”。N 可以小于 5，不能为了数量编造内容或拆碎同一观点。
7. **做来源检查。** 逐张核对：核心知识能在原文找到依据；解释没有扩大结论；例子或答案没有引入原文之外的事实。找不到依据就删除、改成忠实的自测问题，或明确写“原文未说明”。

## 固定输出格式

先输出一行 `共 N 张知识卡片`；信息少于 5 张时紧接着说明原因。然后按重要性编号，每张严格使用以下四个字段：

```markdown
### 卡片 1｜标题
- **核心知识：** 用一句话说清一个可复述的结论、关系或步骤。
- **简明解释：** 用 1–3 句解释核心知识，保留原文条件和范围。
- **例子或自测问题：** 优先给原文中的例子；没有合适例子时提出一个只能用原文回答的问题，并在下一句给出简短答案。
```

卡片标题要能区分知识点，避免使用“重点一”“总结”等空泛标题。自测问题的答案只能来自材料；若材料没有答案，保留问题并标注“原文未提供答案”，不要凭常识作答。卡片之间不要重复同一个核心知识。

## 质量检查

输出前逐项检查：

- 数量在信息允许的范围内，且每张卡片都不可再合并为同一知识点。
- 每张都有标题、核心知识、简明解释、例子或自测问题四项。
- 关键条件、例外、因果关系和不确定措辞没有被删掉或改强。
- 没有把标题、背景、修辞或重复句子单独做成卡片。
- 没有添加原文没有的人名、数字、定义、案例、原因或结论。

如果材料只有一个主题但包含多个相互依赖的细节，宁可少做几张并说明信息不足，也不要把一句话机械拆成多张卡片。
